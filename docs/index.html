01 / 專題計畫

1. 專題名稱

待辦小幫手 LINE Bot。題目為 AI 提案，繳交前由學生確認。

2. 使用對象與用途

給需要快速記下課業或生活事項的學生使用。透過 LINE 輸入待辦，避免臨時想到的任務被遺忘。

3. 核心功能

收到「記錄：待辦事項」後，把非空白文字保存到檔案並回覆確認。第一版只做記錄，不包含查詢、刪除與定時提醒。

4. 對話範例

正常：使用者「記錄：星期五交報告」 → Bot「已記錄：星期五交報告。」
不完整：使用者「記錄：」 → Bot「請輸入要記錄的待辦事項。」

5. AI 協助方式

請 Codex 協助整理需求、撰寫 Node.js 程式、除錯及測試，製作簡報與開發紀錄網頁。學生負責選題、確認需求及完成 LINE 真人測試。

6. 測試計畫

情境一：完整待辦 → 成功保存並回覆確認。
情境二：空白待辦 → 提醒補充，不新增紀錄。
情境三：不支援指令「你好」 → 提供格式與範例，不新增紀錄。

02 / 使用 AI 的開發紀錄

  1. 讀取作業要求：確認一頁六項計畫、GitHub、開發紀錄網頁、簡報 PDF 及實測證明。
  2. 從零縮小需求：依使用者要求建立獨立待辦專案，第一版只做「記錄」，不依賴原有塔羅程式。
  3. 產生與檢查程式：Codex 建立文字指令處理、檔案保存與 LINE Webhook；參照 LINE 官方文件驗證原始請求簽章，再解析事件。
  4. 執行本機測試：檢查正常、空白及不支援指令；另測持久化、相同事件去重、寫入錯誤與 Webhook HTTP 流程。
  5. 整理成果：根據實際輸出製作六項計畫、六頁簡報及本網頁，將未完成的 LINE 測試明確列出。

AI：Codex。回覆採固定規則，沒有呼叫生成式 AI；AI 的用途是協助開發與整理成果。題目與需求由學生確認。
